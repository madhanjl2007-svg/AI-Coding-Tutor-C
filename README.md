# AI Coding Tutor for C Programming

## 1. Project Description

AI Coding Tutor for C Programming is a learning project designed for beginners who are learning C programming.

The project focuses on using AI as a coding tutor to help students understand programming errors, debugging concepts, and problem-solving techniques.

The main approach is to use AI for hints and explanations instead of directly copying answers. Students manually fix the errors and verify the corrected programs using the GCC compiler.

## 2. Problem Statement

Beginners often make mistakes while writing C programs and may find it difficult to identify and understand those errors.

Students may also depend on AI-generated answers without understanding the actual problem.

This project aims to explore how AI can guide students to identify errors, understand concepts, debug programs, and improve their problem-solving skills.

## 3. Project Objective

The objectives of this project are:

* To identify common mistakes made by beginners in C programming.
* To use AI to provide hints and explanations for programming errors.
* To help students understand the reason behind errors.
* To encourage students to manually fix their programs.
* To verify AI suggestions using the GCC compiler.
* To improve debugging and problem-solving skills.
* To understand the limitations and safe use of AI in programming.

## 4. How It Works

The project follows a simple learning and debugging approach:

1. The student provides a buggy C program.
2. AI identifies the possible mistake and gives a hint.
3. AI explains the error and the related concept.
4. The student understands the mistake.
5. The student manually fixes the program.
6. The corrected program is compiled using GCC.
7. The program is executed and the output is verified.
8. The AI response and final result are recorded and evaluated.

**Workflow:**

Buggy Program → AI Hint → Explanation → Student Understanding → Manual Fix → GCC Verification

## 6. Testing and Results

The project contains **15 buggy C programs** covering common beginner programming mistakes.

Each program was tested using the following approach:

**Hint → Explanation → Fix → Manual Testing → GCC Verification**

The AI was tested on all 15 buggy programs.

The AI correctly identified the mistakes and provided useful explanations and fixes during our testing.

The suggested fixes were manually applied and tested using GCC.

The testing showed that AI can be useful for learning and debugging, but its suggestions should always be understood and verified before being trusted.
